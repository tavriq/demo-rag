# RAG по Трудовому кодексу РФ

Демо: вопрос на русском → гибридный поиск по статьям ТК РФ → ответ Claude Haiku 4.5 только по найденным статьям, с цитатой `[ст. N]` у каждого утверждения. Цитаты кликабельны и ведут к фрагменту; найденные фрагменты раскрываются со score. Расходы на модель ограничены жёстким дневным лимитом, счётчик виден на странице.

- **Поиск**: BM25 с русским стеммингом + эмбеддинги `multilingual-e5-small` (int8 ONNX), слияние Reciprocal Rank Fusion. Без векторной БД: numpy + JSON.
- **Ответ**: только по фрагментам; если ответа нет — «В базе нет ответа на этот вопрос.»; вопрос изолирован от инструкций (защита от prompt injection).
- **Cost guard**: дневной лимит в USD по фактическому `usage`, лимит вопросов в час на IP, `max_tokens`, обрезка длинного ввода, вежливый отказ при превышении.
- **Evals**: hit@k и MRR для BM25, dense и гибрида отдельно; с ключом — точность цитат, отказы на вопросах без ответа, стоимость и латентность.

Как устроено и почему так — [docs/design.md](docs/design.md).

## Метрики

Сюда попадают только числа из файлов `evals/` (`latest.md`, `results-<дата>.json`) с датой прогона; на странице они же — `/evals`. Прогонов на рабочем корпусе в репозитории пока нет. Оценка ответов модели (`--answers`) не прогонялась: нужен ключ API.

## Запуск локально

Нужен Python 3.12.

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
python3 -m app.build_index --corpus data/corpus.jsonl      # при первом запуске скачает модель (~125 МБ)
uvicorn --factory app.main:create_app --port 8000 --no-proxy-headers
```

Без `ANTHROPIC_API_KEY` приложение работает в демо-режиме: поиск настоящий, вместо ответа модели показаны найденные фрагменты. С ключом: `export ANTHROPIC_API_KEY=...` перед запуском; в Docker ключ читается из `.env` (шаблон — `.env.example`).

Evals:

```bash
python3 -m app.evals --evals data/evals.jsonl              # только поиск, без LLM
python3 -m app.evals --evals data/evals.jsonl --answers    # + ответы модели, нужен ключ, лимит --max-usd 0.50
```

Тесты (без сети и без ключа, на фикстуре из 15 статей):

```bash
python3 -m pytest
```

## Docker

```bash
docker compose up -d --build     # слушает только 127.0.0.1:18101
```

Контейнер: `python:3.12-slim`, непривилегированный пользователь, `mem_limit: 700m`. Индекс, кеш модели и SQLite с учётом расходов лежат в volume `demo-rag-var`; индекс строится при первом старте и перестраивается, когда меняется корпус. `.env` необязателен.

## Настройки

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | без ключа — демо-режим |
| `DAILY_BUDGET_USD` | `1.00` | дневной лимит расходов на модель, сутки по UTC |
| `RATE_LIMIT_PER_HOUR` | `10` | вопросов в час с одного IP |
| `MAX_TOKENS` | `600` | предел длины ответа |
| `MAX_QUESTION_CHARS` | `500` | длиннее — обрезается |
| `TOP_K` | `5` | сколько фрагментов уходит в модель |
| `TRUSTED_PROXY` | пусто | IP/CIDR прокси, которым можно верить в `X-Forwarded-For` |

Полный список — в `.env.example` и `app/config.py`.

## Ограничения

Это не юридическая консультация. Тексты статей берутся из корпуса с датой редакции и могут отставать от действующей редакции кодекса. Один процесс и SQLite: демо рассчитано на небольшой поток.
